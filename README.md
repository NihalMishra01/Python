## 👨‍💻 About the Repository

> Welcome to my personal **Python Codebase Vault**, where I learn, break, fix, and master core concepts through Jupyter Notebooks. This journey covers everything from fundamentals to object-oriented principles — all documented in clean, modular notebooks.

---

## 🧠 Learning Map

| 📁 Notebook                | 🧩 Concepts Explored                               |
|---------------------------|---------------------------------------------------|
| `exceptionhandling.ipynb` | try-except, error handling, custom exceptions 🔁  |
| `newconditional.ipynb`    | if-else, logical operators, nested conditions 🧠  |
| `newdictionary.ipynb`     | dictionaries, methods, key-value logic 🗂️         |
| `newfunctions.ipynb`      | defining functions, scope, return logic 🧪         |
| `newlist.ipynb`           | list operations, slicing, comprehension 🔄        |
| `newloop.ipynb`           | loops, range, nested loops, control statements ♻️ |
| `newstring.ipynb`         | string methods, formatting, regex basics ✨       |
| `newtuple.ipynb`          | tuples, immutability, packing/unpacking 🌀        |
| `object&classes.ipynb`    | OOP, constructors, inheritance, methods 🧬        |
| `practice.ipynb`          | challenge sets, problem-solving skills 🔍         |
| `readwrite.ipynb`         | file handling, reading/writing, text/CSV 📄       |
